================================================================
 大戦の処理フロー
================================================================

【全ルール共通フロー】
  /rule（ルール選択）
  → /setarmyname（任意：軍名設定）
  → /start（軍選択・初期化）
  → /action（行動 ※ルール別に自動振り分け）
  → 終戦判定（自動 or /finish）
  → /reset（次の大戦へ）

【/action の振り分け】
  rule_type = ranked    → kaikyu_main.js       （階級制撃破判定）
  rule_type = passive   → PassiveSkill.mjs     （パッシブスキル制）
  rule_type = skillgein → Skillgein/action.mjs （技能習得制）
  rule_type = senyuu    → senyuu/senyuu_main.js（戦友制）
  rule_type = coin      → /coin-fire 等を案内
  rule_type = beast     → /beast を案内
  rule_type = fighting  → /punch /charge /burst を案内

【軍BOBの流れ】
  main.mjs の ready イベント → startArmyBobTimer(client)
  → 60秒ごとに checkAndActBobs()
  → armybob_enabled / 終戦 / armybob_interval を確認
  → adjustBobCounts()で人間の人数に応じてBOBを着任・撤退
  → rule_typeごとの execute○○BobsForArmy() を A軍・B軍の順に実行
  → 各BOBの投稿は4秒間隔（BOB_ACTION_DELAY_MS）

【ルール別のDBカラム（Userテーブル）】
  階級制          rank
  属性コイン制    personal_○○_coin（5属性）
  ビースト制      beast_name / beast_atk / beast_is_active / beast_has_fed
  ファイティング制 fight_value
  技能習得制      skill_atk / skill_magic / skill_spirit / skill_snipe / skills_data
  戦友制          comrades_data（前衛・中衛・後衛の3枠をJSONで保持）
  軍BOB共通       bob_type（性格タイプ。skills_dataとの衝突を避けるため専用カラム）

【/reset の使い方】
  /reset                通常リセット（データのみ削除、構造保持）
  /reset force_recreate:True  完全リセット（緊急用・通常は不要）
  ※新カラム追加後に「no such column」が出た場合のみ force_recreate を使う
